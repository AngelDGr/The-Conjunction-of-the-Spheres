Формулы - это алхимические рецепты для создания зелий, масел и бомб. 
В каждой формуле перечислены необходимые ингредиенты и описан тип основы, необходимый для создания смеси. 

Эти формулы можно найти в разных сундуках по всему миру или получить, торгуя с деревенскими жителями. 
__Вы должны знать рецепт, чтобы приготовить элексир.__

;;;;;

Рецепты для [элексиров](^tcots-witcher:concoctions/decoctions) можно найти только в __Древних городах__.
